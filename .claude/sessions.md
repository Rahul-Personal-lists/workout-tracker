- **Calorie estimate fix** ([estimates.ts](src/lib/estimates.ts)): `estimateCalories` charged the MET model on *work-seconds only* (sets×reps×3s), excluding inter-set rest — undercounting a lifting session ~3–4× (a ppl-5d Push read ~55 cal). Now uses `activeSeconds` (work + rest, the same per-exercise term as duration; warm-up buffer still excluded). Same-day examples now read realistically: Push ~177 cal / 31 min, Full Body A ~209 cal / 34 min. Affects every "~cal" readout (hub day, library detail, preset preview).
